# Build Prompt: FPL Mini-League Manager

## The Product Vision

Build a modern web application called **FPL League Manager**.

This platform is designed for Fantasy Premier League (FPL) mini-leagues that want more ways to compete against their friends.

Fantasy Premier League is the underlying game and scoring system. This application sits on top of FPL and gives mini-league managers tools to create custom competitions, tournaments, schedules, standings, and league rules.

The core idea is:

> **FPL provides the fantasy teams. FPL League Manager provides the competitions.**

The website should feel like a modern sports league management platform combining elements of:

* Fantasy Premier League
* ESPN Fantasy Football
* NFL fantasy playoffs
* March Madness brackets
* FA Cup / League Cup competitions
* UEFA Champions League
* FIFA World Cup group stages

The product should be exciting, competitive, social, and highly customizable.

The design should feel like a premium sports platform rather than a traditional corporate dashboard.

---

# CORE USER FLOW

## Step 1: Create an Account

Users can:

* Create an account
* Log in
* Create a new league
* Join an existing private league using an invitation link or code

The user who creates the league automatically becomes the **League Manager**.

---

# STEP 2: CONNECT AN EXISTING FPL MINI-LEAGUE

League Managers should be able to connect their existing FPL mini-league to the platform.

The system should allow the manager to enter:

* FPL mini-league ID
* League name
* Season

The application should retrieve and store:

* All managers in the league
* Team names
* FPL manager names
* Overall league standings
* Gameweek scores
* Total points
* Historical gameweek scores

The platform should treat FPL as the source of truth for fantasy points.

The application should use the official FPL public data endpoints where possible.

Create a data architecture that can automatically synchronize league standings and scores after each FPL gameweek.

# FEATURE 1: TRADITIONAL FPL LEAGUE TABLE

Display the normal FPL standings.

Columns should include:

* Rank
* Manager
* Team Name
* Gameweek Points
* Total Points
* Previous Rank
* Rank Movement

Use arrows or indicators to show movement up or down the standings.

Make the standings visually engaging and easy to scan.

---

# FEATURE 2: HEAD-TO-HEAD LEAGUE

This should be one of the flagship features.

Allow league managers to create a custom Head-to-Head competition using normal FPL gameweek scores.

Example:

Manager A scores 67 points.

Manager B scores 61 points.

Manager A wins the matchup.

Standings use traditional American fantasy football scoring:

* Win = 3 points
* Draw = 1 point
* Loss = 0 points

Display a full league table containing:

* Rank
* Manager
* Wins
* Losses
* Draws
* Points For
* Points Against
* Point Difference
* League Points
* Current Streak

---

## Head-to-Head Scheduling

Allow league managers to:

* Automatically generate a schedule
* Manually edit matchups
* Choose which gameweeks the competition runs
* Select the number of regular-season weeks
* Create playoff brackets

For example:

28 managers could play:

* A regular season
* Playoffs for the top 8 managers
* Consolation playoffs
* Championship game

The schedule should intelligently avoid duplicate matchups when possible.

---

# FEATURE 3: FPL CUP TOURNAMENT

Allow managers to create a knockout cup competition.

The tournament should support:

* Single elimination
* Two-legged ties
* Random draws
* Seeded draws
* Automatic advancement
* Byes

The league manager should be able to select:

* Tournament name
* Start gameweek
* End gameweek
* Number of participants
* Seeding method
* Tie-breaking rules

Example:

A 28-team league begins with a preliminary round.

The competition progresses through:

* Preliminary Round
* Round of 16
* Quarterfinals
* Semifinals
* Final

Each matchup is determined by FPL points during the selected gameweek.

The platform should automatically update the bracket.

Create a visually impressive knockout bracket similar to an FA Cup or March Madness tournament.

---

# FEATURE 4: WORLD CUP-STYLE TOURNAMENT

This is a major feature.

League managers should be able to create a group-stage tournament.

Example:

28 managers are randomly placed into:

7 groups of 4 managers.

Each manager competes against the other managers in their group.

The league manager should be able to configure:

* Number of groups
* Number of managers per group
* Number of teams advancing
* Random or seeded groups
* Match format
* Tournament start gameweek

Group standings should include:

* Played
* Wins
* Draws
* Losses
* Goals For / Points For
* Goals Against / Points Against
* Difference
* Tournament Points

Use:

* Win = 3 points
* Draw = 1 point
* Loss = 0 points

After the group stage, automatically generate a knockout bracket.

The system should support:

* Round of 16
* Quarterfinals
* Semifinals
* Third-place match
* Final

The application should intelligently handle awkward numbers of teams such as:

* 20 teams
* 24 teams
* 28 teams
* 32 teams

Create tournament visuals that feel similar to a professional soccer competition.

## Participants

## Time Period

# FEATURE 6: PLAYOFF SYSTEM

Create a fantasy football-style playoff system.

The league manager can choose:

* Top 4
* Top 6
* Top 8
* Top 12
* Custom number of playoff teams

Support:

* Single elimination
* Two-week aggregate matchups
* Byes for higher seeds
* Reseeding after each round

The playoff system should automatically create the bracket based on regular-season standings.

Example:

Seed 1 receives a bye.

Seed 2 receives a bye.

Seed 3 plays Seed 6.

Seed 4 plays Seed 5.

The winners advance automatically.

Examples:

Highest gameweek score.

## Biggest Bottler

Manager who had the largest drop in rank.

## Heartbreak of the Week

# IMPORTANT PRODUCT PRINCIPLES

The website should NOT try to replace Fantasy Premier League.

It should complement Fantasy Premier League.

The core user experience should be:

1. A group of friends already plays FPL.

2. They connect their existing mini-league.

3. Their league manager creates custom competitions.

4. The website automatically uses FPL scores to determine results.

5. Managers now have:

* Head-to-head leagues
* Cups
* Group stages
* Playoffs
* Tournaments
* Awards
* League history
* Rivalries
* Records

The goal is to make a normal FPL mini-league feel like a complete fantasy sports league with its own identity, competitions, history, and traditions.

## Phase 3

Add:

* Awards
* Rivalries

* League History
* Record Book
